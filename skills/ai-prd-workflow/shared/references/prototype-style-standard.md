# 原型样式交付标准

用于统一团队原型在评审与分享时的视觉质量。目标不是做品牌创意设计，而是让原型稳定、清楚、专业、可评审。

## 1. 视觉目标

- 克制
- 专业
- 业务感明确
- 可长期复用
- 不依赖个人审美发挥

## 2. 字体与层级

- 标题、正文、辅助信息必须有清晰层级
- 同角色文本在不同页面使用同一字号和字重
- 正文优先保证可读性，不要过小
- 注释、说明、占位文本可弱化，但不可弱到难读

## 3. 布局与间距

- 页面边距、区块间距、表单间距使用稳定节奏
- 相关信息紧密分组，不相关内容留出明显分隔
- 不使用杂乱的任意间距值
- 不为了填满页面而堆卡片和装饰容器

## 4. 组件一致性

- 按钮样式保持统一的主次关系
- 输入框、下拉框、选择器、表格、标签、提示样式保持一致
- 相同状态使用相同颜色和视觉信号
- 不同页面的同类控件不要出现明显风格漂移

## 5. 状态表达

至少统一以下状态：

- 默认态
- 悬停态
- 聚焦态
- 禁用态
- 错误态
- 成功态
- 空状态
- 加载态

## 6. 颜色使用

- 颜色优先服务信息传达，不为装饰而装饰
- 主色、警示色、成功色、错误色语义固定
- 不使用过强渐变、发光、玻璃态等抢戏效果
- 原型优先保持企业业务系统的稳定观感

## 7. 适配要求

- Web 原型应保证桌面评审清晰可读
- 移动端原型应保证主要操作区和信息层级清楚
- 不允许因样式统一而牺牲小屏可读性

## 8. 完成交付的最低标准

- 主要页面在同一风格体系下
- 关键状态表达完整
- 字体、间距、组件样式无明显冲突
- 可以直接用于团队评审和分享
