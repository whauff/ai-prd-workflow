# 减法检查清单

每轮主要输出后运行。开始重复，就停止扩写，转向收口。

## 减法检查

- 重复入口？
- 重复解释？
- 页面噪音？
- 内部信息外露？
- 本机路径或不可共享内容？
- 漂移到技术设计？

## 同步检查

多交付物并存时检查：

- 命名一致？
- 状态一致？
- 判断顺序一致？
- 范围前提一致？
- 字段层级一致？
- 多端权限一致？
- 链接有效？

## 变更同步规则

- 影响范围、状态、字段、规则、权限、流程或异常处理的变更，必须回看 Brief、PRD、原型、规则稿和流程图。
- 仅样式、排版或措辞微调，不触发业务同步。
- 原型新增按钮、字段、状态、异常提示或权限差异时，必须检查 PRD 是否同步。
- 流程图新增分支或例外时，必须检查 PRD 或规则稿是否已有对应处理策略。

## 旧产物治理

- 哪些是最终交付？
- 哪些应归档？
- 哪些应删除？
- 是否默认只暴露最终版入口？
