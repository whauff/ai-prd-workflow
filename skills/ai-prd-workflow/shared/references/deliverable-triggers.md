# 交付物触发条件

按内容触发交付，不按模板习惯堆交付。

## 什么时候出原型

- 需求涉及页面或表单。
- 交互状态本身很重要。
- 大概率会在界面或行为上产生分歧。

## 什么时候出规则稿

- 需求需要定义识别或校验规则。
- 系统需要拦截、提示、打标、评分或分类。
- 边界样本会影响判断口径。

## 什么时候出流程图

- 逻辑包含关键分支。
- 有保存前或保存后的处理。
- 存在同步、解析、回写或异常链路。
- 文字已经开始不如图示清楚。

## 什么时候停止扩产物

- 核心问题、目标和方案已经清楚。
- 当前对象已有足够材料。
- 没有新增分歧。
- 新增交付物只会重复已有内容。
