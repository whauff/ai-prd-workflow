# PRD 模板

最小可用 PRD 模板。未命中章节可跳过。若已有 Brief，沿用其范围、顺序、字段和权限口径。复杂规则拆独立规则稿，正文只保留摘要和链接。

## 1. 背景

说明当前问题、现状，以及为什么现在要做。

## 2. 目标

说明预期业务结果，以及如何判断这次需求是否达成。

## 3. 用户与场景

说明谁会受到影响，以及这个需求在哪些场景下成立。

## 4. 方案概述

尽量简短地概述这次准备怎么做。

## 5. 交互与页面

只在页面、表单、状态或交互变化确实重要时展开。

## 6. 规则与治理

只在存在复杂业务规则口径时使用，例如识别、拦截、打标、评分、分类、计算、分配、结算、权益、价格、优先级或例外。规则复杂时链接规则稿，不在正文展开。

## 7. 验收标准

说明满足什么条件后，这次需求可以视为完成。

## 8. 风险与待确认

只列尚未收敛且影响评审的问题。
