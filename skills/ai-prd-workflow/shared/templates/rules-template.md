# 规则稿模板

用于对齐复杂业务规则口径。重点写适用条件、判断或计算口径、处理策略、优先级、例外情况和边界样本。不要写成小 PRD 或规则引擎设计。

## 1. 规则目标

说明这套规则要解决什么问题。

## 2. 规则决策表或规则矩阵

每条规则至少说明：

- 规则名称
- 适用条件
- 判断、计算、分配或适配口径
- 结果或处理方式
- 优先级
- 例外情况
- 备注

## 3. 判断信号或适用条件

列出关键词、模式、样本特征、主体、市场、渠道、订单类型、时间范围等条件。

## 4. 边界样本或规则示例

列出高争议样本或典型示例，并说明为什么这样判或这样计算。

## 5. 处理策略

说明命中或适配后的处理。按需使用：

- 拦截
- 提示
- 一键优化
- 打标
- 允许通过
- 分佣
- 结算
- 权益发放
- 价格调整
- 人工复核

## 6. 当前版本说明

说明这一版覆盖了什么，以及哪些边界情况有意留到后续版本再处理。
