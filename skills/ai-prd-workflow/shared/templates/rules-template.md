# 规则稿模板

这份模板用于对齐判断口径。重点是命中条件、处理策略和边界样本。不要把它写成一份小 PRD，也不要把它写成规则引擎技术设计。

## 1. 规则目标

说明这套规则要解决什么问题。

## 2. 规则决策表

这是正文核心。每一条规则至少说明：

- 规则名称
- 命中条件
- 处理方式
- 是否阻断
- 是否提示
- 是否影响治理或评分
- 备注

## 3. 判断信号

列出关键词、模式、样本特征或其他支持判断的信号。

## 4. 边界样本

列出最容易引起争议的真实样本，并说明为什么这样判。

## 5. 处理策略

说明命中后系统怎么处理：

- 拦截
- 提示
- 一键优化
- 打标
- 允许通过

## 6. 当前版本说明

说明这一版覆盖了什么，以及哪些边界情况有意留到后续版本再处理。
